## Creating an Icon

You can create a custom icon or use these resources:
- Use tools like GIMP, Photoshop, or online icon generators
- Recommended: Clock/history themed icon in blue/white colors
- Format: PNG with transparency
- Size: 64x64 or 128x128 pixels
